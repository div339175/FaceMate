# FaceMate biometric-data policy

FaceMate is an attendance tool, not an identity-surveillance system. Use it only
with clear institutional approval and informed student consent.

- Enrollment images are processed to create facial embeddings; original
  enrollment images are deleted by the application after successful processing.
- Face embeddings, attendance records, and profile data are sensitive. Limit
  access to authorized staff, encrypt backups, and never publish these files.
- A face match is a recommendation. Teachers must be able to review and correct
  attendance before finalising it.
- Define a retention period, an opt-out/manual-attendance process, and a way for
  students to request correction or deletion where required by local law.
- Do not expose this development instance directly to the public internet.
